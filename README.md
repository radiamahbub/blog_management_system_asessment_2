🌸 Blog Management System

A simple and elegant Blog Management System built with Django 🐍✨

This project allows users to create, manage, and explore blog posts with a clean and straightforward interface.

✨ Features
👤 User Registration & Login
✍️ Create Blog Posts
📖 View Blog Posts
📝 Update Blog Posts
🗑️ Delete Blog Posts
🏷️ Blog Categories
🖼️ Image Upload
🔐 User Authentication
📱 Bootstrap-based responsive interface
🛠️ Built With
Technology	Purpose
🐍 Python	Programming Language
🌿 Django	Web Framework
🗄️ SQLite	Database
🌐 HTML	Structure
🎀 Bootstrap	Styling & Responsive UI
🚀 Run Locally
1. Clone the repository
git clone <YOUR_REPOSITORY_URL>
2. Navigate to the project
cd blog_management_system_asessment_2
3. Create a virtual environment
python -m venv venv
4. Activate the virtual environment

Windows:

venv\Scripts\activate
5. Install Django
pip install django
6. Apply database migrations
python manage.py migrate
7. Start the development server
python manage.py runserver
8. Open the project 🌷

Visit:

http://127.0.0.1:8000/

📂 Project Overview

The system provides the basic functionality needed to manage a blog, including authentication, post creation and editing, categories, and image uploads.

It's a small Django project created for learning and practicing CRUD operations, authentication, database management, templates, and Bootstrap UI development.
