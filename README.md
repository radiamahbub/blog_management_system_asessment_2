Blog Management System

A simple blog management system built with Django.

Features

User registration and login

Create blog posts

View blog posts

Update blog posts

Delete blog posts

Blog categories

Image upload

Built With

Python

Django

SQLite

HTML

Bootstrap

Run Locally
git clone <repository-url>
cd blog_management_system_asessment_2

python -m venv venv
venv\Scripts\activate

pip install django

python manage.py migrate
python manage.py runserver


Open http://127.0.0.1:8000/ in your browser.
